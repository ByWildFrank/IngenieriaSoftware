𝗣𝗿𝗼𝗱𝘂𝗰𝘁 𝗕𝗮𝗰𝗸𝗹𝗼𝗴 📋
Historias de usuario priorizadas para la jugabilidad principal:

Mover Cañón (3 pts, Alta Prioridad): Usa ←→ para esquivar y apuntar. 🎮
Disparar Proyectiles (4 pts, Alta Prioridad): Presiona barra espaciadora para eliminar enemigos. 🔫
Formaciones Enemigas (5 pts, Alta Prioridad): Enfrenta enemigos que se mueven y desaparecen al ser impactados. 👾
Escudos Destructibles (5 pts, Media Prioridad): Bloquea disparos con escudos temporales. 🛡️
Platillo Volador (3 pts, Media Prioridad): Destruye el platillo para puntos extra. 🛸
Fin del Juego (4 pts, Alta Prioridad): Pierdes si los enemigos alcanzan el cañón. 💥
